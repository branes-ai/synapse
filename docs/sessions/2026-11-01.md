## The rule

Every license ADR in the stack now says the same thing about data:

- A third-party dataset, vocabulary or set of pretrained weights may be
  committed or fetched only under a license the ADR (or synapse's ledger)
  records.
- Data without a license, or under a non-commercial or share-alike license
  (CC BY-NC, CC BY-SA, …), stays outside the repo.
- **Published facts are not data.** Calibration parameters, sensor
  specifications and results printed in a paper may be written into the repo's
  own files, with a citation. A file copied from a dataset is the dataset's,
  and follows the rule.

The facts allowance was not in the original racing-drone and scout-drone
wording. It was added because of what checking cortex turned up.

## cortex and EuRoC

Before adding the rule, each repo was checked for third-party data it already
has. reflex and anatomy have none. synapse keeps model weights out of the repo
already. cortex uses EuRoC MAV for its VIO accuracy gates. The ETH Research
Collection record for EuRoC
([10.3929/ethz-b-000690084](https://doi.org/10.3929/ethz-b-000690084)) gives its
rights as "In Copyright - Non-Commercial Use Permitted". The ASL dataset pages
state no license of their own.

- **The sequences** are read from a copy the developer supplies
  (`CORTEX_EUROC_*`, `CORTEX_EUROC_ROOT`). cortex never commits or downloads
  them, which the rule allows.
- **The hello_vio fixtures** under `examples/hello_vio/testdata/` held
  EuRoC's own `cam0/sensor.yaml` and `imu0/sensor.yaml`, copied, in both
  `mav0/` and `frames/mav0/`. The rule as first worded would have excluded
  them.
- **EuRoC cam0's intrinsics and distortion** (458.654, 457.296, …) are
  hard-coded in about 25 files across `tests/`, `tools/`, `bench/` and the
  bench fixtures. (The question put to the user said seven test files; that
  count was from a truncated search.)
- **The synthetic frames** in `frames/mav0/` are generated by
  `gen_frames_fixture.py`, so they were already fine.

The user chose the facts allowance over removing EuRoC's calibration from
cortex. In cortex#559 the four copied files became cortex-written files in the
same ASL layout, with a header citing Burri et al., "The EuRoC micro aerial
vehicle datasets" (IJRR, 2016). Parsed, every key holds the same value as
before except the free-text `comment`. The SITL and MSVC builds ran
`hello_vio.smoke` and `hello_vio.frames` on them before the merge. The fixture
README, the example README and the generator's docstring now describe the
files as EuRoC's published calibration rather than the dataset's own files.
cortex's ADR 0001 records all of this.

## synapse (#86)

ADR 0001's weights rule now covers any third-party data, checked against
`THIRD_PARTY_NOTICES.md`. Its current state names the one third-party data
file in the repo, `tests/data/spm_vocab.gguf`. That is Llama 2's SentencePiece
vocabulary, copied from llama.cpp, which distributes it under MIT. The
vocabulary itself comes from Meta's tokenizer. It meets the rule as written,
because its license is recorded, but its origin is a model's tokenizer rather
than llama.cpp's own work.
