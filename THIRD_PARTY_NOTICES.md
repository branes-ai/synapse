## llama.cpp and ggml

<https://github.com/ggml-org/llama.cpp>, MIT License.

synapse reads the models llama.cpp runs, and parts of it are ports of llama.cpp and ggml code, kept close to the original so results match. Each ported header says so and points here:

| synapse | llama.cpp / ggml source |
|---|---|
| `tokenizer/spm.hpp` | `llm_tokenizer_spm_session` and the SentencePiece branch of `llama_vocab::tokenize` (`src/llama-vocab.cpp`) |
| `tokenizer/bpe.hpp` | `llm_tokenizer_bpe_session` (`src/llama-vocab.cpp`) |
| `tokenizer/vocab.hpp` | `tokenizer_st_partition` and the token-type handling (`src/llama-vocab.cpp`) |
| `tokenizer/pretokenize.hpp` | `unicode_regex_split_custom_llama3`, and the Qwen2 and Tekken split regexes (`src/unicode.cpp`, `src/llama-vocab.cpp`) |
| `tokenizer/unicode.hpp` | UTF-8 decoding and the GPT-2 byte map (`src/unicode.cpp`) |
| `quant/blocks.hpp` | the `block_*` layouts (`ggml/src/ggml-common.h`) and `dequantize_row_*` (`ggml/src/ggml-quants.c`) |
| `quant/q8.hpp` | `quantize_row_q8_0_ref`, `quantize_row_q8_K_ref` and `nearest_int` (`ggml/src/ggml-quants.c`) |
| `kernels/dot.hpp` | the arithmetic of `ggml_vec_dot_*_q8_*_generic` (`ggml/src/ggml-cpu/`) |
| `kernels/attention.hpp` | the RoPE cache, `rope_yarn` and `ggml_rope_yarn_corr_dims` (`ggml/src/ggml-cpu/ops.cpp`, `ggml/src/ggml.c`) |
| `tests/data/spm_vocab.gguf` | `models/ggml-vocab-llama-spm.gguf`, copied unchanged |

The test fixtures written by `scripts/` (the `*_golden.gguf` files and the tiny models) are llama.cpp's output, not its code. The GGUF reader (`gguf/`) is written from the file format and checked against llama.cpp's `gguf-py`.
